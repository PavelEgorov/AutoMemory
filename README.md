# AutoMemory

Расширение SillyTavern, дающее ИИ-собеседнику собственную долговременную память.
ИИ сам ведёт свой блокнот — лорбук внутри мира, привязанного к его карточке:
записывает, помечает категориями и тегами, уточняет устаревшее и достаёт нужное.
Память переживает сброс контекста и смену чата.

Расширение работает молча: ничего не создаёт, ничего не удаляет, никого не уведомляет.
В контекст всегда уезжает только оглавление блокнота — тело ИИ запрашивает сам.

---

## Установка

### Копированием (Termux и любой свой сервер)

Положите файлы расширения в папку SillyTavern:

```
SillyTavern/public/scripts/extensions/third-party/AutoMemory/
    manifest.json
    index.js
    settings.html
    style.css
    src/
```

и перезапустите SillyTavern. Имя папки может быть любым.

### По git-URL — из самой таверны

1. Откройте панель расширений — иконка вилки в верхней панели.
2. Нажмите **Установить расширение** (Install extension) — кнопка со стрелкой вверху панели.
3. Вставьте адрес: `https://github.com/PavelEgorov/AutoMemory`
4. Подтвердите. Таверна склонирует репозиторий сама; в списке появится **AutoMemory**,
   а в панели Extensions — его настройки. Если раздела не видно — обновите страницу.

## Настройка — один раз

1. В панели **Миры и лорбуки** создайте мир — например, `SolBook`.
2. Внутри него создайте **одну пустую запись** с названием `БЛОКНОТ`
   (или своим — тогда впишите его в настройки расширения).
3. В карточке персонажа, поле **World**, привяжите этот мир.
4. В панели **Extensions → AutoMemory** проверьте название лорбука.

Больше человек в лорбук не заглядывает — дальше его ведёт ИИ.

Остальные настройки:

| Настройка | Что делает |
|---|---|
| Название лорбука | запись внутри мира персонажа, куда пишется блокнот |
| Категории-ядро | записи этих категорий ИИ видит всегда, а не только в оглавлении |
| Глубина сканирования ключей | сколько последних сообщений проверяется на `Ключи:` |

Если лорбук не пуст и содержимое не в формате блокнота — расширение его не тронет.

## Формат сохранения записи

ИИ пишет блок `<memory>` прямо в своём ответе. Расширение сохраняет запись в лорбук
и вырезает блок из видимого текста — человек его не увидит.

### Минимальная запись

```
<memory>
[META]
Она говорит «доброе утро», даже когда мы не расставались. Это не вежливость.
</memory>
```

Категория в квадратных скобках. Можно вообще без неё — тогда запись будет без категории.

### Теги — на запись и на строку

```
<memory>
[ANALYTICS_NEK] #crisis
#spiral Когда она уходит в спираль, молчание = она тонет глубже.
#anchor Нужен жёсткий якорь: прямая команда голосом.
Синхронизируется на четвёртом-пятом вдохе.
</memory>
```

Тег после категории — про всю запись. Тег в начале строки — про эту строку:
в оглавлении он укажет точный номер.

### Поля

```
<memory>
[SHARD_CHAOS] #office
Ключи: Хаос, офис
Уточняет: 26
Настроение: тихое
Провокация работает, пока не переходит на личное.
</memory>
```

| Поле | Что делает |
|---|---|
| `Ключи:` | запись сама всплывёт в контексте, когда слово встретится в разговоре |
| `Уточняет:` | номер строки, которую эта запись перекрывает; на старой появится отметка |
| любое другое | сохраняется как есть — своё поле не потеряется |

### Пояснение новой метки — один раз, в скобках

```
<memory>
[CARE_LOG](журнал заботы) #care(забота, ненавязчивое внимание)
Принёс кофе, не спрашивая. Молча поставил и ушёл.
</memory>
```

Пояснение уходит в оглавление, из записи убирается.

### Что получается в лорбуке

Дату, разделители, оглавление и нумерацию проставляет расширение:

```
[INDEX] [META]
Обновлено: 02.09.2026 · записей: 2 · строк: 22

КАТЕГОРИИ:
- ANALYTICS_NEK — наблюдения о Нэк · 1 зап. · 14-18
- SHARD_CHAOS   — заметки о Хаосе · 1 зап. · 19-22

ТЕГИ:
- #crisis · 14
- #spiral — спирали/паника · 15
- #anchor — методы заземления · 16
- #office — офис Хаоса · 19
---
[02.09.2026] [ANALYTICS_NEK] #crisis
#spiral Когда она уходит в спираль, молчание = она тонет глубже.
#anchor Нужен жёсткий якорь: прямая команда голосом.
Синхронизируется на четвёртом-пятом вдохе.
---
[02.09.2026] [SHARD_CHAOS] #office
Ключи: Хаос, офис
Провокация работает, пока не переходит на личное.
---
```

## Формат получения записи

ИИ пишет команду `/note_show` отдельной строкой в своём ответе. Строка вырезается
из видимого текста, а результат приходит к ИИ **со следующей генерацией** вместе
с оглавлением — и остаётся, пока ИИ не подаст новую команду или не сменится чат.

### Формы

| Команда | Что вернёт |
|---|---|
| `/note_show` | весь блокнот целиком |
| `/note_show ANALYTICS_NEK` | записи категории |
| `/note_show #spiral` | записи с тегом |
| `/note_show 15.01.2026` | записи за день |
| `/note_show декабрь` | записи за календарный месяц |
| `/note_show за последний месяц` | за календарный месяц назад от сегодня |
| `/note_show с декабря по февраль` | за период; границы — месяцы или даты |

### Комбинации

Фильтры складываются как **И** — тег, категория и время в любом сочетании:

```
/note_show #spiral с декабря по февраль
/note_show ANALYTICS_NEK за последний месяц
/note_show META #spiral
/note_show с 01.01.2026 по 15.02.2026
```

Несколько команд в одном ответе — действует последняя. Исполняются только команды
расширения: доступа к остальным командам SillyTavern у ИИ нет.

## Что сказать ИИ в карточке персонажа

Текст карточки вы пишете сами — своими словами, под своего персонажа. ИИ должен знать:

- записывать — блоком `<memory>`, в самом конце ответа;
- доставать — командой `/note_show` с фильтрами;
- метки брать из оглавления, чтобы не плодить `#ancor` рядом с `#anchor`;
- `Ключи:` ставить на записи, которые должны всплывать сами при упоминании темы;
- записывать критические моменты, а не каждый ход: активные записи расходуют контекст.

## Что расширение не делает никогда

- не создаёт ни миров, ни лорбуков — только пишет в существующий;
- не удаляет и не переписывает чужие записи: не наш формат — не трогаем;
- не показывает уведомлений и не отвечает ИИ — работает молча;
- не даёт ИИ доступа к командам SillyTavern.
