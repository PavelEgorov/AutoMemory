# AutoMemory

Расширение SillyTavern, дающее ИИ-собеседнику собственную долговременную память.
ИИ сам ведёт свой блокнот — лорбук внутри мира, привязанного к его карточке:
записывает мысли, помечает их категориями и тегами, уточняет устаревшее и достаёт
нужное. Память переживает сброс контекста и смену чата.

Расширение работает молча: ничего не создаёт, ничего не удаляет, никого не уведомляет.
В контекст всегда уезжает только оглавление блокнота — остальное ИИ берёт сам.

---

## Как подключить

**Из таверны:**

1. Откройте панель расширений — иконка вилки в верхней панели.
2. Нажмите «Установить расширение» — кнопка со стрелкой вверху панели.
3. Вставьте адрес: `https://github.com/PavelEgorov/AutoMemory`
4. Подтвердите и обновите страницу. В панели Extensions появится раздел AutoMemory.

**Или копированием** — положите файлы в
`SillyTavern/public/scripts/extensions/third-party/AutoMemory/` и перезапустите таверну.

**Разовая настройка:**

1. В панели «Миры и лорбуки» создайте мир — например, `SolBook`.
2. Внутри него создайте пустую запись. Название любое — как назовёте,
   так и впишите в поле «Название лорбука» в настройках расширения.
3. В карточке персонажа, поле **World**, привяжите этот мир.
   Именно в карточке — список «Активные миры для всех чатов» не подойдёт.
4. Для выборки включите **Function Calling** в настройках API-подключения
   (Claude, OpenAI, OpenRouter и совместимые это умеют).

Больше человек в лорбук не заглядывает — дальше его ведёт ИИ.

## Настройки

**Включено** — главный выключатель. Снята галка: блоки не обрабатываются,
оглавление в контекст не уезжает, инструмент выборки модели не предлагается.

**Не вырезать блоки из сообщений** — по умолчанию блок `<memory>` убирается
из видимого текста. С этой галкой он остаётся в чате как есть; записи при этом
сохраняются как обычно. Удобно, чтобы видеть, что именно пишет ИИ.

**Подробный лог в консоль** — отладка: каждая операция пишется в консоль браузера.

**Название лорбука** — как называется запись в мире, куда пишется блокнот.
Имя любое; регистр и квадратные скобки не важны, запись может начинаться
с вписанного: «[БЛОКНОТ SOL]» подходит под «БЛОКНОТ» — так одно поле
обслуживает всех персонажей.

**Категории-ядро** — через запятую. Записи этих категорий ИИ видит всегда,
целиком, а не только строкой в оглавлении. Для самого важного: кто он,
о чём договорились. По умолчанию пусто.

**Глубина сканирования ключей** — сколько последних сообщений проверяется
на слова из `Ключи:`. Совпало — запись сама всплывает в контексте.

**Последняя операция** — не настройка, а строка состояния внизу панели:
что произошло с последним блоком. Если запись не сохранилась, здесь будет
написано почему.

## Как пользоваться

### ИИ записывает

Блок `<memory>` в конце ответа. Минимум — просто текст, можно с категорией:

```
<memory>
[META]
Она говорит «доброе утро», даже когда мы не расставались. Это не вежливость.
</memory>
```

Теги: после категории — про всю запись, в начале строки — про эту строку:

```
<memory>
[ANALYTICS_NEK] #crisis
#spiral Когда она уходит в спираль, молчание = она тонет глубже.
#anchor Нужен жёсткий якорь: прямая команда голосом.
</memory>
```

Поля — сразу после категории. `Ключи:` — слова, по которым запись сама всплывёт
в разговоре. `Уточняет:` — номер строки, которую эта запись перекрывает.
Любое своё поле сохранится как есть:

```
<memory>
[SHARD_CHAOS] #office
Ключи: Хаос, офис
Уточняет: 26
Провокация работает, пока не переходит на личное.
</memory>
```

Новой метке можно один раз дать пояснение в скобках — оно уйдёт в оглавление:

```
<memory>
[CARE_LOG](журнал заботы) #care(забота, ненавязчивое внимание)
Принёс кофе, не спрашивая. Молча поставил и ушёл.
</memory>
```

Дату, разделители, оглавление и нумерацию расширение проставляет само.

### ИИ читает

Инструментом `note_show` — вызывает его посреди своего ответа и сразу получает
результат. Аргумент один, строка-фильтр:

- пусто — весь блокнот целиком;
- `ANALYTICS_NEK` — записи категории;
- `#spiral` — записи с тегом;
- `15.01.2026` — записи за день;
- `декабрь` — записи за календарный месяц;
- `за последний месяц` — календарный месяц назад от сегодня;
- `с декабря по февраль` — период; границы — месяцы или даты.

Фильтры складываются как И, в любом сочетании:

```
#spiral с декабря по февраль
ANALYTICS_NEK за последний месяц
META #spiral
```

Если по фильтру ничего нет или блокнот недоступен — инструмент отвечает об этом
словами, ИИ не остаётся в неведении.

### Карточка персонажа

Текст пишете сами, своими словами. ИИ должен знать:

- записывать — блоком `<memory>`, в самом конце ответа;
- доставать — инструментом `note_show` с фильтром;
- метки брать из оглавления, чтобы не плодить `#ancor` рядом с `#anchor`;
- `Ключи:` ставить на записи, которые должны всплывать сами при упоминании темы;
- записывать критические моменты, а не каждый ход.

## Что должно получиться

После пары записей та самая запись в мире выглядит так — оглавление собирается само,
номера строк настоящие:

```
[INDEX] [META]
Обновлено: 02.09.2026 · записей: 2 · строк: 22

КАТЕГОРИИ:
- ANALYTICS_NEK — наблюдения о Нэк · 1 зап. · 14-18
- SHARD_CHAOS   — заметки о Хаосе · 1 зап. · 19-22

ТЕГИ:
- #crisis · 14
- #spiral — спирали/паника · 15
- #anchor — методы заземления · 16
- #office — офис Хаоса · 19
---
[02.09.2026] [ANALYTICS_NEK] #crisis
#spiral Когда она уходит в спираль, молчание = она тонет глубже.
#anchor Нужен жёсткий якорь: прямая команда голосом.
Синхронизируется на четвёртом-пятом вдохе.
---
[02.09.2026] [SHARD_CHAOS] #office
Ключи: Хаос, офис
Провокация работает, пока не переходит на личное.
---
```

В чате при этом чисто: блоки вырезаны (если не включена галка «Не вырезать»),
персонаж просто разговаривает — и помнит.
